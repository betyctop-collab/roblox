# Requirements

## Original ask

Make a Roblox **RNG game** with:
- Same repo as the wave-based prototype, but a **new branch** (don't break
  the existing PR / `init` branch).
- **Delete the wave-based code.** Start fresh from the empty `init` branch.
- **Anime katana** theme.
- **Auto-roll every ~5 seconds + click-to-roll boost** as the core loop.
- **8 rarity tiers** with 1/N drop chances spanning 1/2 → 1/1,000,000.
- **Server-wide announcements** for Mythic-and-rarer drops.
- **Same place** as the previous game (`Universe 10137511986`,
  `Place 105682311495562`) — replaces the wave-based version on publish.
- **UI is mine to design** ("ui сам сгенерируй и все остальное").
